# 接入与验收清单

> 出口版本：`dsh-elysia 0.1.0`　｜　验收时间：装好后 10 分钟内能走完

## 一、装之前

| 检查 | 命令 | 期望 |
|---|---|---|
| Node 版本 | `node -v` | ≥ 22.12 |
| DSH 版本 | `dsh --version` | 0.2.x（与插件同 release 线） |
| 本地构建 | `npm run build` | 产出 `lib/index.js` 与 `lib/index.d.ts` |
| 逻辑自测 | `npm test` | 47 条全绿 |
| 装配冒烟 | `npm run test:smoke` | 6 条全绿（用桩宿主，不依赖 DSH） |

## 二、装

```sh
dsh plugin --profile desktop add file:E:/Elysia/dsh-elysia
```

装完**重开桌面应用**（`dsh web` 用 `--profile web` 并重启进程）——运行中的进程持有内存里的旧插件，热装看不到效果。

## 三、八条命令的验收点

| # | 命令 | 期望 | 不通过先看 |
|---|---|---|---|
| 1 | `/elysia 你好呀` | 一两句话、口语、称呼「主人」，**正文里没有** `[emotion:...]` | 模型是否配好；`maxReplyChars` 是否被裁到看不见 |
| 2 | 再问 `/elysia 你还记得我叫什么吗`（前面说过「我叫X」） | 能叫出名字 | `memoryEnabled`；`<dshHome>/dsh-elysia/state.json` 里 `facts` 是否有 `name` 槽 |
| 3 | `/elysia-mood` | 输出「心情：开心（71/100）」这类一行 | 心情只在对话/主动后变化，刚装是 70 |
| 4 | `/elysia-memory` | 留空出总量；给词出召回段 | 给词时若「没想起来什么」，检查该词是否只在寒暄里出现 |
| 5 | `/elysia-say` | 立刻得到一句主动的话，并出现在 `/elysia-inbox` 里，计数 +1 | 若回「正处于安静时段」，把 `quietStartHour/quietEndHour` 改成 0 再试 |
| 6 | `/elysia-forget` 然后 `/elysia-forget confirm` | 第一次拒绝，第二次清空（`/elysia-memory` 归零） | 只清记忆，心情需删文件才复位 |

## 三·补、桌宠开屏

| # | 动作 | 期望 |
|---|---|---|
| 1 | 重开桌面应用 | 她从屏幕右侧外滑进来（约 0.9 秒），落地直接切静态 `ide`（抱爱心坐垫），不展翅、不冒报到气泡 |
| 2 | 设置页点「召唤桌宠」 | 同样从右侧滑入一次；点「收起桌宠」先挥手再消失 |
| 3 | 开屏那几秒内 | 不会叠第二条「早上好/晚上好」的报到问候，也不会插自动动作 |

判读不通过时：确认装的是新 `lib/client.js`（搜 `introStamp`）、浏览器没拦住首次音频（需一次点击或已有交互）。

## 四、真实等待

自动主动开口由每分钟的闸门决定，**装好后不会有「立刻响一下」的效果**，这是设计如此（五道闸门 + 55% 抽签）。手动验收用 `/elysia-say`；要观察自动行为，把 `proactiveChance` 临时调成 1、`proactiveMinGapMin` 调成 1。

## 五、故障对照

| 现象 | 最可能的原因 |
|---|---|
| 命令根本没出现 | 没重新启动 DSH；`enabled` 为 false；`dsh plugin list` 里没有 `dsh-elysia` |
| 她一直「没说出话来」 | 模型 ID / 服务商写错（DSH 侧表现为空回复）；看 `/elysia` 的结构化错误文案 |
| 回复被换成「唔…这句话我还是藏在心里好了」 | 命中提示词泄露或敏感词（`sensitiveWords`）；查日志里的 gate hits |
| 存档没生成 | 宿主没有 `setInterval` / `commands` 时会只告警不崩；确认 `<dshHome>` 可写 |
| 记忆串味 | 一份存档对应一个 DSH 用户；多用户需按 profile 隔离（当前未做） |

## 六、回滚与重置

```text
删除 <dshHome>/dsh-elysia/state.json   → 记忆 + 心情 + 主动计数全部归零
```

插件本体卸载：

```sh
dsh plugin --profile desktop remove dsh-elysia
```

## 七、已知限制（验收时按这个尺度判）

- 无流式：整段生成完再回帖，长回复体感慢。
- 心情判定是轻量的：只认模型末尾的情绪标签，拿不到 confidence，也不写时间线。
- 已接：窗口内桌宠浮层、独立透明桌面版（自动启动、右键菜单、聊天/设置）、设置页卡片、语音输入（`/listen`）、朗读（`/speak`）、提醒；未接：PetLink。
